# Task Manager

A simple Task Manager application built with Node.js, Express, MongoDB, HTML, CSS, and JavaScript.

## Features

- Create tasks
- View tasks
- Edit tasks
- Mark tasks as completed
- Delete tasks

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- HTML
- CSS
- JavaScript
